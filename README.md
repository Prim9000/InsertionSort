# Insertion Sort Lab

An interactive, single-file web page for learning insertion sort.
Students drag the cards, and the page updates `x`, `y` and `Temp`,
highlights the matching Python line, and builds a pass-by-pass table
like Figure 23.01.

Number sets: Classic (5, 2, 4, 1), Figure 19.3 (9 cards) and
Figure 23.01 (6 cards), plus a random set.

No build step, no dependencies, no network requests.

## Publish with GitHub Pages
1. Create a new repository on GitHub (for example `insertion-sort-lab`).
2. Upload `index.html` and `README.md` to the repository root
   (Add file > Upload files).
3. Open Settings > Pages. Under "Build and deployment", set Source to
   "Deploy from a branch", choose the `main` branch and the `/ (root)` folder, then Save.
4. After a minute the site is live at
   `https://<your-username>.github.io/insertion-sort-lab/`.

To try it locally, double-click `index.html`.
